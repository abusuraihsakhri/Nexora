# Source Scaffold

This directory mirrors the Phase 2 architecture and contains interface/header scaffolding only.
It is not presented as a fully implemented or hardware-validated kernel.

Integration dependencies:
- actual Nexora Phase 1 PMM API
- bootloader/firmware memory-map code
- kernel allocator
- IDT/exception infrastructure
- build system and project conventions

The `docs/` directory is the authoritative specification in this archive.
